# Data

Datasets are not committed to the repository (see `.gitignore`).

## How to get the data

1. Download a phishing email dataset from Kaggle (search "Phishing Email Dataset").
2. Put the CSV file into this folder, for example `data/emails.csv`.
3. Note the names of the text and label columns, you will pass them to the script.
